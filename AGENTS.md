# Repository agent entrypoint

Before changing this repository:

1. Read `docs/WORKING_AGREEMENTS.md`.
2. Read the relevant status, architecture, hardware, and test documents.
3. Inspect open issues and pull requests for active ownership and stacked work.
4. Treat chat history as context, not project authority.
5. Do not promote experimental results into another repository's requirements or BOM without its explicit decision gate.
6. Leave the standard handoff block in every pull request.
